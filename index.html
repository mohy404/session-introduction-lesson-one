02Hardware

ما هو Hardware؟

Hardware هو كل جزء مادي في جهازك — أي حاجة تقدر تشوفها بعينك أو تمسكها بإيدك. هو الجزء اللي بينفذ العمليات فعليًا، وبيخزن بياناتك، وبيستقبل أوامرك، وبيطلعلك النتيجة قدامك.

CPURAMMotherboard SSDHDDGPU MonitorKeyboardMouse PrinterNetwork Card
الـ CPU من الـ Hardware، لأنه جزء مادي جوه جهازك تقدر تلمسه فعليًا — وهو المسؤول عن تنفيذ العمليات.

أنواع الـ Hardware

مش هنغوص في تفاصيل هندسية دلوقتي، الهدف بس إنك تبني صورة صح في دماغك.

Processing

الأجزاء اللي بتنفذ العمليات وتعالج البيانات فعليًا جوه جهازك.

CPUGPU

Memory & Storage

الـ Memory (زي RAM) بتخزن البيانات مؤقتًا وقت التشغيل بس، أما الـ Storage (زي SSD وHDD) فبتخزن بياناتك بشكل دائم حتى لو قفلت الجهاز.

RAMSSDHDD

Input Devices

الأجهزة اللي بتدخل بيها بيانات أو أوامر للجهاز.

KeyboardMouseMicrophoneCamera

Output Devices

الأجهزة اللي بيطلعلك بيها الجهاز النتيجة قدامك.

MonitorSpeakersPrinter

Networking Hardware

الأجهزة اللي بتوصّل جهازك بالإنترنت أو بأجهزة تانية.

Network CardRouterWi-Fi Adapter
03Software

طيب.. إيه هو Software؟

Software هو مجموعة البرامج والتعليمات اللي بتقول للـ Hardware يعمل إيه، وإزاي ينفذ المهمة المطلوبة. عكس الـ Hardware تمامًا، الـ Software مش حاجة مادية — منفعش تلمسه، بس تقدر تشغّله وتستخدمه.

WindowsLinuxAndroid ChromePhotoshopMicrosoft Word GamesWeb ApplicationsMobile Applications
لأ. Windows مثلًا Software — تقدر تستخدمه وتشغّله، بس مش جسم مادي تقدر تمسكه بإيدك زي الـ Hardware.

أنواع الـ Software

System Software

البرمجيات المسؤولة عن تشغيل الجهاز وإدارته، وتجهيز البيئة اللي البرامج التانية هتشتغل فوقيها.

Operating SystemsDevice DriversSystem Utilities

Application Software

البرامج اللي إنت بتستخدمها فعليًا عشان تنجز مهمة معينة.

BrowsersWord ProcessorsDesign SoftwareGames

05Operating System

إيه هو نظام التشغيل؟

نظام التشغيل (Operating System) هو البرنامج الأساسي اللي بيدير موارد جهازك، وبيوفر البيئة اللازمة عشان باقي البرامج تشتغل، وبيتفاهم مع الـ Hardware نيابة عنها.

تخيل جهازك شركة صغيرة:

Hardware الموظفين والمعدات

المبنى والأدوات والناس اللي بينفذوا الشغل فعليًا.

Applications الأقسام

الأقسام اللي بتقدم الخدمات المختلفة للعملاء.

Operating System المدير

اللي بينظم استخدام الموارد ويوجّه شغل الكل.

التشبيه ده للتقريب بس، مش تعريف تقني دقيق.

09Programming

طيب.. إيه هي البرمجة بالظبط؟

البرمجة هي عملية كتابة تعليمات وأوامر باستخدام لغة برمجة، عشان الكمبيوتر ينفذ مهمة أو مجموعة مهام.

التعريف ده صح.. بس لوحده مش كفاية عشان تفهم البرمجة فهم حقيقي.

البرمجة هي تحويل مشكلة أو هدف إلى خطوات منطقية قابلة للتنفيذ بواسطة الكمبيوتر.

المبرمج مش بيبدأ دايمًا بكتابة الكود. هو بيفكر الأول:

01ما المشكلة؟
02ما المطلوب تحقيقه؟
03ما البيانات المتاحة؟
04ما القواعد والشروط؟
05ما الخطوات المنطقية للحل؟
06إزاي نحول الخطوات دي لـ Algorithm؟
07إزاي نحول الـ Algorithm لـ Code؟
08إزاي نختبر الحل؟
09إزاي نحسّنه ونطوّره؟
شبه كود (Pseudocode) — مش لغة برمجة حقيقية، بس بيوضح طريقة التفكير
// لسه ماكتبناش أي كود فعلي.. وده متعمد if (المشكلة واضحة) { حدد("المطلوب"); صمم("الخطوات"); }
لأ، المبرمج الحقيقي بيفكر الأول في المشكلة والحل قبل ما يكتب أي سطر كود.
10البرمجة في عالم الأعمال

البرمجة مش بس "أكتب كود عشان أتعلم"

في الواقع، البرمجة بتُستخدم لبناء حلول لمشاكل حقيقية.

البرمجة هي استخدام التفكير المنطقي والخوارزميات والبرمجيات لبناء حلول لمشكلات حقيقية — سواء كان الهدف تحسين عملية، توفير وقت، تقليل تكلفة، تقديم خدمة، أو تحقيق عائد مادي.

11مثال بسيط

مثال هيوضحلك الفكرة بسرعة

صاحب محل عايز يعرف إجمالي مبيعات اليوم أوتوماتيك، من غير ما يجمعها بإيده وهو ممكن يغلط.

INPUT

أسعار المنتجات وكمياتها

PROCESSING

السعر × الكمية لكل منتج

OUTPUT

إجمالي المبيعات

نفس الفكرة، بس مكتوبة كشبه كود
// input: قائمة المنتجات (سعر، كمية) total = 0 for each منتج in القائمة: total += منتج.السعر × منتج.الكمية print(total) // output: إجمالي المبيعات

ودي بالظبط فكرة أي برنامج بسيط: Input → Processing → Output. البرمجة هي اللي بتحدد إزاي هيحصل التحويل من مرحلة للتانية.

المبرمج

ليس مجرد شخص يكتب Code، بل شخص يستخدم التفكير المنطقي لبناء حلول لمشكلات حقيقية.

المبرمج ما بيتعلمش البرمجة عشان يكتب Code بس؛ هو بيتعلم إزاي يحوّل المشاكل لحلول منطقية يقدر الكمبيوتر ينفذها.
قيمة البرمجة بتظهر لما نستخدمها لبناء حلول حقيقية بتوفر وقت، تقلل تكلفة، تحسّن عملية، تقدّم خدمة، أو تخلق قيمة ممكن تتحول لعائد.
